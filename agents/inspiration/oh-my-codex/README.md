## What is included

Only the following trees were copied from upstream, verbatim at the snapshot commit above:

- `prompts/` — agent prompt templates
- `skills/` — skill definitions (`SKILL.md` and related files)

This is not a full vendoring of OMX, and it is not an installable or runnable copy of the upstream package.
